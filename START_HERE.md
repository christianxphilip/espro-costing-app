# ☕ START HERE - Café Costing App

## 🎯 What This App Does

Calculate costs and pricing for your café menu items automatically!

- Track ingredients and their costs
- Manage operating expenses (rent, utilities, labor)
- Get AI-powered pricing suggestions
- Import/export Excel files
- View analytics and insights

---

## 🚀 How to Run (Super Simple)

### Step 1: Make sure Docker Desktop is installed and running

Download from: https://www.docker.com/products/docker-desktop/

### Step 2: Open terminal in this folder

### Step 3: Run this command:

```bash
./start.sh
```

### Step 4: Open your browser

Go to: **http://localhost:3000**

---

## ✅ That's It!

The app is now running with:
- ✅ Frontend (React app)
- ✅ Backend API (Node.js)
- ✅ Database (MongoDB)
- ✅ All configurations automatic

---

## 🎓 First Steps in the App

1. **Go to "Expenses"** → Add operating expenses (rent, utilities, etc.)
2. **Go to "Items"** → Add your café menu items with ingredients
3. **Click 🤖** → Get AI pricing suggestions
4. **View "Dashboard"** → See your analytics

---

## 🛑 How to Stop

Press `Ctrl+C` in the terminal, then:
```bash
docker-compose down
```
